3. AUTHORITATIVE MEMORY MAP & PERIPHERAL SLOTS
--------------------------------------------------------------------------------
Slot | Peripheral Description      | Address Range           | Size  | Protocol
-----+-----------------------------+-------------------------+-------+-------------------------
M00  | Instruction RAM (Firmware)  | 0x0000_0000-0x0000_FFFF | 64 KB | AXI4 Full 32-bit
M01  | Data RAM (Stack/Heap/BSS)   | 0x0001_0000-0x0001_FFFF | 64 KB | AXI4 Full 32-bit
M02  | UART 16550 Controller       | 0x0002_0000-0x0002_0FFF |  4 KB | AXI4-Lite (via adapter)
M03  | 32-bit Timer / PWM          | 0x0002_1000-0x0002_1FFF |  4 KB | AXI4 Full 32-bit
M04  | 32-bit GPIO Controller      | 0x0002_2000-0x0002_2FFF |  4 KB | AXI4 Full 32-bit
M05  | Packet FIFO Registers       | 0x0002_3000-0x0002_3FFF |  4 KB | AXI4-Lite (via generic)
M06  | CRC-32 Checker Engine       | 0x0002_4000-0x0002_4FFF |  4 KB | AXI4-Lite (via generic)
M07  | Packet Statistics Counter   | 0x0002_5000-0x0002_5FFF |  4 KB | AXI4 Full 32-bit

--------------------------------------------------------------------------------
4. INTERRUPT MAPPING (VeeR EL2 PIC)
--------------------------------------------------------------------------------
The VeeR EL2 Programmable Interrupt Controller (pt.PIC_TOTAL_INT = 31) routes:
  IRQ 1: Timer Match Event (timer_top)
  IRQ 2: GPIO Input Transition Event (gpio_top)
  IRQ 3: Packet FIFO Watermark / Full Event (packet_fifo_top)
  IRQ 4: CRC-32 Check Complete / Error Event (crc_top)
  IRQ 5: UART Rx Ready / Tx Empty Event (axi_uart_top)
  IRQ 6: Packet Counter Overflow Event (packet_counter_axi)
  IRQ 7..31: Reserved / Tied to 1'b0

5. KEY FILES CREATED & MODIFIED
--------------------------------------------------------------------------------
1. rtl/soc_top.v
   Complete SoC top-level module integrating CPU subsystem, 3x8 crossbar, 8
   subordinate peripherals, streaming packet datapath, and event pulse routing.

2. rtl/cpu/veer_cpu_subsystem.sv
   Processor subsystem wrapping veer_wrapper, internal SRAM models (DCCM, ICCM,
   ICache data ram_512x71, ICache tag ram_64x26), IFU/LSU adapters, and PIC
   interrupt aggregation.

3. rtl/wrappers/veer_ifu_axi64_to_axi32_wrapper.v
   Converts VeeR EL2 IFU 64-bit single-beat burst fetches (ARLEN=0, ARSIZE=3'b011)
   into two sequential 32-bit read bursts on 32-bit interconnect port S00.

4. rtl/wrappers/veer_lsu_axi64_to_axi32_wrapper.v
   Converts VeeR EL2 LSU 64-bit data transactions to 32-bit transactions for S01.

5. rtl/adapters/axi4_to_axi4lite_generic_adapter.v
   Bridges AXI4 subordinates M05 (FIFO) and M06 (CRC) to AXI4-Lite with
   independent AW/W capture and RLAST generation.

6. rtl/adapters/axi4_to_axi4lite_uart_adapter.v
   Bridges AXI4 subordinate M02 to the 16550 UART register interface. Fixed
   axi_uart_bvalid_o signal declaration.

7. rtl/IPs/fifo/packet_fifo_top.v
   Added dedicated single-cycle pulse output `fifo_overflow_o` connected to
   packet_counter_axi.

8. docs/soc_test_plan.md
   Complete 4-tier verification and test plan detailing 36 test cases
   (TP-001 through TP-036).
